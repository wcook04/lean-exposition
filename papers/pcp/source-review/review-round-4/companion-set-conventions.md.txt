## 8. Markers and mapping (do not break)
- Marker syntax (docs/authoring.md:574-576; alignment.py:30; contracts.py:972-1003): `<!-- passage:ANCHOR -->` ... `<!-- /passage:ANCHOR -->`, one pair per anchor, no overlap, no nesting, no unmapped marker, no duplicate, non-empty.
- `text_sha256` in each mapping row = sha256 of the exact UTF-8 bytes between the two markers (newlines included). Any edit inside a passage, even whitespace, makes "passage content hash is stale" (contracts.py:1003). `content_sha256` = hash of the whole file (authoring.md:589). `graph_sha256` binds the graph (and companions cited by graph source checksum, authoring.md:545-550).
- Editor may not: delete/rename markers or anchors; add text between passages that makes a material claim without mapping (checker cannot see it); change the ids of passages with `reading_links` or `treatments` (mapping has them: pcp/long/reasoning-record.json 22 reading links, SK long 10, SK short 3; PCP short and expo mappings have 0 reading links).
- After every prose edit: recompute `text_sha256` for changed passages and `content_sha256`; re-hash every reading-link endpoint, including incoming links authored in another paper (bundle.py:280-290 rejects stale endpoints); revisit rationale/claims for changed meaning (hash refresh is not correctness); keep the `draft`/review state honest; then `lean-exposition validate examples/pcp/evidence-graph.json`, `lean-exposition assemble ... --out build/pcp-authored`, `lean-exposition check-bundle build/pcp-authored` (README.md "Assemble a reader bundle"; cli.py:98, 295). The alignment code also resolves explicit `<a id=...>` and pandoc-style heading ids (alignment.py:31-44), so keep heading text stable where mapped.
- Statement: new passages need new anchors and mapping rows (claim_ids, citation_ids, assumption_ids, evidence_class, rationale); SK short mapping state is draft/needs_revision, PCP draft/not_reviewed.
PCP should adopt: nothing new; follow authoring.md:574-640. Before editing, snapshot hashes and write a small script to rehash after edits.
