## Preservation boundaries

Existing mathematical displays, numerical parameters, algorithms, corrector sampling steps, 187-query upper bound, soundness gap and repetition count are retained. The added `Phi` display defines existing notation. The seven-row table expands an already claimed resource bound. This patch does not optimize the verifier, replace its degree-three encoding with a quadratic encoding, or substitute a deterministic label for the random homogeneous label.

It retains the mutable public example-checker URL while adding a separate frozen-packet route. It does not edit any companion, modify the reader/site, or claim to implement the whole pedagogical redesign. In particular, the fair-coin internal tester interface and the complete continuous example still belong in the proposed structural revision. Applying only this patch would improve local accuracy and reconstructibility but would not demonstrate that the paper meets its full learner promise.
