# Decisions on proposed method changes

The returned method proposals were advisory. The changes below apply existing source and reader contracts; they do not create another authoring system.

**Exact edition before historical criticism (long M01).** Applied to the alleged general homogeneity statement and to the old scalar-test counterexample. In the first case, the supplied v1/v2 papers do not contain the broader statement described in a Lean comment, so the criticism was removed. In the second, the retained v1 does contain the faulty test and v2 corrects it, so the specific comparison remains. Exception: an assertion about another historical draft requires that exact draft; its absence is not evidence of what it said. Existing edition-specific citation rules already own this requirement.

**Unknown extraction is not an empty successful report (long M02).** Implemented in the generic reader, with regression coverage for source-only declarations, statement-compiled records and actual extracted axiom reports. A successfully extracted empty report can support its recorded scope; an absent report cannot. The final display and analytics preserve this distinction.

**Browser routes need their own checks (specialist M01).** Implemented for both relative Markdown companion links and legacy fragment URLs. The tests cover heading arrival, Back restoration and an open Lean view. PDF annotations are checked separately against named PDF destinations. Exception: an external ordinary URL remains an external navigation, not an internal paper route.

**Keep the existing contents rail (specialist RD02).** The demonstrated full-width closed-pane defect was repaired. A new collapsible desktop control was an optional preference, so it was not added without evidence that it improved this reader's use. Laptop and monitor layouts were inspected.

The exposition return proposed no new general rule requiring a new skill. Its missing prerequisites, carried examples, conditional probability accounting and exercise ordering are addressed through the existing exposition method. No global skill rewrite was warranted by this revision.
