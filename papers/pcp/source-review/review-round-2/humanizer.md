## Editorial decisions

The full record keeps the algebraic derivations, exceptional slices and error-event accounting. New prose supplies missing warrants: formal polynomial recovery, the purpose of the ruled surface, the four mixed-plane discrepancies and both reference-NP simulations. The new byline makes the explanatory authorship visible without suggesting a new theorem.

The specialist account replaces compressed transitions with short operational descriptions. Its table inventory describes arbitrary received tables before honest encodings. Its decoding steps name the label domain, the common polynomial and the error being bounded. Large decimal constants move to exact companion sections; the symbolic proof remains in place.

The exposition introduces total degree, grid tuples and binary field coordinates before using them. It moves the detailed clause compiler and exact error constants behind the main argument. The reconstruction exercise precedes the solution. Its answer follows the same certificate polynomial, target point, random correction and rejection event throughout. These changes increase the length because the requested examples require the missing intermediate operations.

Across the three papers, the literal-language pass removed repeated inventories and vague references, corrected machine-model terminology and distinguished addresses from stored bits. Necessary negations remain: arbitrary received tables need not be honest encodings; proximity on one label domain does not imply proximity on another; an axiom report that was never extracted is unknown. Such distinctions carry mathematics and are not stylistic clutter.
