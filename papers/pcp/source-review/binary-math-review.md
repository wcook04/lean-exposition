## Ranked actionable finding

1. **Soundness of completeness sentence — missing honest-oracle hypotheses.** At `pcp-long-zero-actual-test`, “If the certificate is honest and has degree strictly below b^c, both calls are exact, so (B19) proves perfect completeness for every seed” is false as stated. Both corrector calls also need their auxiliary line tables to be honest; and the second check compares with the primary oracle, which also must be honest. A corrupted primary bit can force rejection despite an honest certificate. Compare `PCP/Algebraic/BinaryZeroOnGridCorrection.lean`, `check` lines 64–75 and `check_eval` lines 141–155, and `BinaryLocalCorrection.lean`, `run` lines 47–60. **Correction:** “If the primary table is H₁(P), the certificate table is H₁(M), and both correction auxiliaries are their honest encoded line tables, with deg M < b^c, both calls return the required values for every seed; (B19) gives perfect completeness.” Notified author and parent.

2. **Hypothesis clarity, lower priority.** `pcp-long-binary-weighted-test` and outer-correction passages speak of “the same nodes” and “the formal” assumptions. The formal theorem actually accepts a generator-node table for testing and a separately supplied ζ satisfying `GoodNodes` for correction; they need not be equal (`BinaryLocalCorrectionSoundness.lean:222–233`; definitions in `GeneratorLowDegreeTest.lean:30–38`, `StandardLocalCorrection.lean:17–24`). Using a single generator for both is a valid special case and matches the actual construction; label it explicitly as a specialization, so the chapter does not imply the theorem requires equality or leave the correction node assumptions implicit.

3. **Dependency completeness, lower priority.** (B25) requires the derived map x ↦ A_x(g(x)) to be the evaluation of a polynomial P of total degree at most D; arbitrary point-dependent A_x is not by itself enough. The text says “where P(x)=A_x(g(x))” and earlier supposes P has degree ≤D, so the necessary condition is recoverable, but repeat it at (B25), especially since “A_x may depend on the outer point” could suggest unrestricted x dependence always suffices. Compare `DerivedZeroOnGridSoundness.lean:246–260` (`hvalue`, `hP`, `hQ`).
