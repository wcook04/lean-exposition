# Authoring transitions

These skills teach decisions that the CLI cannot make. They can be read by a
human or copied into an agent's supported skill directory. The Python package
does not load or execute them.

| Starting point | Task | Skill |
| --- | --- | --- |
| Identified source files | Record claims, assumptions and their support | [Source to graph](source-to-graph/SKILL.md) |
| A validated graph and selected goal | Write a reconstructible argument | [Graph to long record](graph-to-long/SKILL.md) |
| An authored long record | Select a coherent research paper | [Long record to short paper](long-to-short/SKILL.md) |
| An established result and its argument | Explain that result to a specified reader | [Record to exposition](record-to-expository/SKILL.md) |

Use the [authoring guide](../docs/authoring.md) for the shared evidence and
review contract. These stages may expose a mathematical gap. Record that gap
and return to research; a writing transition cannot fill it by changing the
claim's wording.
